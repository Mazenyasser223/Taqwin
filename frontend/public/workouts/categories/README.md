# Exercise library category covers

Photos for muscle-zone and equipment-group browse tiles in the Exercise Library (`/workouts`).

- **Source:** Curated [Unsplash](https://unsplash.com) images (free license).
- **Sync:** `npm run sync:exercise-categories --prefix backend-node`
- **Frontend mapping:** `frontend/features/workouts/exerciseCategoryTheme.ts`
- **Browse UI:** `frontend/features/workouts/` (category grid + filters)

Files are named `{categoryId}.jpg` (e.g. `chest.jpg`, `free-weights.jpg`).
